# CHANGELOG.md

История изменений утилиты **copy-file**, являющейся частью библиотеки **sherpa-rpa-common-blocks**.
Утилита `copy-file` предназначена для надежного копирования файлов с автоматическим созданием директорий.

---

## Что фиксируется в CHANGELOG

В CHANGELOG включаются только **проверенные и значимые изменения**, влияющие на:
- функциональность утилиты,
- контракт данных (входные/выходные параметры),
- обработку ошибок,
- документацию,
- версионирование.

> ❌ Локальные эксперименты, временные правки и отладочные изменения **не включаются**.

---

## Стандарт классификации изменений

Используется терминология **Conventional Commits** для описания типа изменений:

- **`feat`** — добавление новой функциональности (например, новый параметр, поддержка списков)
- **`fix`** — исправление ошибки или нестабильного поведения
- **`docs`** — изменения в документации (SPEC, README, комментарии)
- **`chore`** — рутинные задачи (версионирование, инициализация)
- **`refactor`** — переработка структуры без изменения внешнего поведения
- **`style`** — исправление опечаток, форматирование

> 💡 Тип может уточняться через область в скобках: `feat(copy-file)`, `docs(spec)`, `chore(version)`.

---

## Формат версионирования

Используется **Semantic Versioning (MAJOR.MINOR.PATCH)**:

- **MAJOR** — изменения, нарушающие обратную совместимость (`BREAKING CHANGE`)
- **MINOR** — обратно совместимое расширение функциональности (`feat`, `refactor` с новыми возможностями)
- **PATCH** — обратно совместимые исправления и улучшения (`fix`, `docs`, `style`, `chore`)

> Каждая версия отражает **логически завершённый и проверенный** набор изменений.

## История изменений

### [1.0.0] - 2026-09-22

#### `feat(copy-file)`
- Базовая функциональность копирования файлов из источника в целевую папку
- Автоматическое создание недостающих директорий (включая вложенные)
- Проверка длины пути с лимитом 256 символов
- Структурированный вывод результатов через HashTable (`result`)
- Стандартизированное логирование в формате `[INFO]:[copy-file]`
- Обработка ошибок без прерывания работы родительского сценария
- Поддержка абсолютных и относительных путей
- Возможность копирования в рабочую директорию робота (если `destination_folder_path` не указан)
- Перезапись файла по умолчанию, если он уже существует в целевой папке

#### `docs(copy-file)`
- Создана техническая спецификация (SPEC.md)
- Создана пользовательская документация (README.md)
- Зафиксированы стандарты разработки (CONVENTIONS.md)
