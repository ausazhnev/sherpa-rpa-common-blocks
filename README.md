# Sherpa RPA Common Blocks (СШК)

Библиотека диаграмм СШК для Sherpa RPA. Готовые переиспользуемые компоненты для ускорения разработки и production-автоматизации.

## 📖 О проекте

Данный репозиторий содержит набор стандартизированных и протестированных диаграмм (утилит) для платформы Sherpa RPA.

Главная цель библиотеки — исключить дублирование кода и повысить надежность RPA-сценариев. Каждая утилита инкапсулирует типовую задачу (например, работу с файловой системой, сетью или API), обрабатывает все возможные исключения и возвращает структурированный результат, предотвращая нештатное падение робота.

## 📏 Стандарты разработки

Все компоненты в этом репозитории разрабатываются в строгом соответствии с внутренним регламентом. Это гарантирует единообразие, предсказуемость и простоту поддержки.

👉 [Посмотреть полные конвенции разработки (CONVENTIONS.md)](CONVENTIONS.md)

**Ключевые принципы:**
- **Единый стиль:** Строгое именование файлов (`kebab-case`), переменных (`snake_case`) и логов.
- **Отказоустойчивость:** Утилиты никогда не роняют родительский процесс. Ошибки перехватываются и возвращаются в структурированном формате.
- **Прозрачность:** Каждая утилита сопровождается полной документацией (`SPEC.md`, `README.md`, `CHANGELOG.md`).

## 🚀 Быстрый старт

1. Перейдите в [каталог утилит](utils/) и выберите нужный компонент.
2. Ознакомьтесь с документацией утилиты (`README.md`).
3. Скачайте файл `<имя-утилиты>.process` в свой проект.
4. Добавьте диаграмму в Sherpa Designer и укажите необходимые параметры.

> ⚠️ **Важно:** Все утилиты создаются с использованием локальных переменных проекта.
