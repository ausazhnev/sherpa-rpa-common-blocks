## 🔍 Как выбрать утилиту

Каждая утилита решает конкретную задачу. Для выбора подходящего компонента:

1. Определите задачу, которую нужно автоматизировать
2. Найдите соответствующую утилиту в таблице выше
3. Изучите её документацию (`README.md`) для понимания параметров и ограничений
4. При необходимости ознакомьтесь с полной спецификацией (`SPEC.md`)

## 📐 Общие принципы

Все утилиты библиотеки следуют общим принципам разработки СШК:

- **Отказоустойчивость:** Утилиты обрабатывают ошибки внутри себя и не прерывают выполнение родительского процесса
- **Стандартизация:** Единый стиль именования, логирования и документирования
- **Переиспользование:** Каждая утилита спроектирована для многократного использования в разных проектах

Подробные конвенции разработки: [CONVENTIONS.md](../CONVENTIONS.md)
