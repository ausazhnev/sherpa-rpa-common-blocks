# Утилита перемещения файлов (move-file)

Надежная утилита для перемещения файлов в Sherpa RPA. Автоматически создает недостающие директории, валидирует длину пути и возвращает структурированный результат, предотвращая нештатное падение робота. Использует безопасный паттерн "копирование → проверка → удаление", при котором исходный файл удаляется только после успешного подтверждения записи в новое место.

## ✨ Ключевые особенности

- **Гарантия пути**: Автоматически создает всю цепочку вложенных папок, если они отсутствуют.
- **Защита от длинных путей**: Явная проверка лимита в 256 символов с понятным сообщением об ошибке.
- **Безопасность данных**: Исходный файл удаляется только после успешного завершения операции записи в целевую папку.
- **Безопасность исполнения**: Любые ошибки перехватываются и возвращаются в структурированном виде. Робот не падает с «красным текстом».
- **Гибкость**: Поддержка абсолютных и относительных путей. Возможность перемещения в рабочую директорию робота без указания целевой папки.

## ⚙️ Аргументы

### Входные параметры (In)

| Имя | Тип | Обязательный | По умолчанию | Описание |
| --- | --- | --- | --- | --- |
| `source_file_path` | String | ✅ Да | — | Полный путь к исходному файлу. |
| `destination_folder_path` | String | ❌ Нет | `''` (пустая строка) | Путь к целевой папке. Если не указан, файл будет перемещен в корневую рабочую директорию сценария робота. |

### Выходные параметры (Out)

| Имя | Тип | Описание |
| --- | --- | --- |
| `result` | HashTable | Объект с результатами операции. Содержит ключи: |

**Структура HashTable `result`:**

- `is_success` (Boolean): `$True` при успехе, `$False` при ошибке.
- `status_message` (String): `"OK"` или подробное описание ошибки.
- `new_file_path` (String): Итоговый абсолютный путь к перемещенному файлу (пустая строка при ошибке).

## 📝 Примеры использования

**Сценарий 1: Перемещение в новую вложенную структуру (например, архивация)**

Вход:
- `source_file_path`: `C:\Data\temp\report.xlsx`
- `destination_folder_path`: `D:\Archive\2026\09\Reports\`

Результат:
Утилита создаст папки `2026\09\Reports\` (если их нет), переместит файл, удалит исходник из `C:\Data\temp\` и вернет `is_success = $True`.

**Сценарий 2: Перемещение в рабочую директорию робота**

Вход:
- `source_file_path`: `.\downloads\config.json`
- `destination_folder_path`: (оставляем пустым)

Результат:
Файл `config.json` будет перемещен в корневую папку, откуда запущен робот.

## 📊 Логирование

Утилита использует стандартизированный формат логов для удобства фильтрации:
- Начало: `[INFO]:[move-file]: Запуск обработки...`
- Конец: `[INFO]:[move-file]: Обработка завершена`

## ❗ Обработка ошибок

В случае любой ошибки утилита не прерывает работу родительского сценария. В поле `status_message` будет возвращен понятный текст:
- `"Путь к источнику не может быть пустым"`
- `"Исходный файл не найден: ..."`
- `"Превышен лимит длины пути: ..."`
- `"Ошибка создания директории: ..."`
- `"Ошибка копирования файла: ..."`
- `"Файл скопирован успешно, но не удалось удалить исходный файл: ..."`
- `"Ошибка выполнения задачи - ..."` (для любых непредвиденных ситуаций)
