# Утилита копирования файлов (copy-file)

Надежная утилита для копирования файлов в Sherpa RPA. Автоматически создает недостающие директории, валидирует длину пути и возвращает структурированный результат, предотвращая нештатное падение робота.

## ✨ Ключевые особенности
- **Гарантия пути:** Автоматически создает всю цепочку вложенных папок, если они отсутствуют.
- **Защита от длинных путей:** Явная проверка лимита в 256 символов с понятным сообщением об ошибке.
- **Безопасность:** Любые ошибки перехватываются и возвращаются в структурированном виде. Робот не падает с «красным текстом».
- **Гибкость:** Поддержка абсолютных и относительных путей. Возможность копирования в рабочую директорию робота без указания целевой папки.

## ️ Аргументы

### Входные параметры (In)

| Имя | Тип | Обязательный | По умолчанию | Описание |
|-----|-----|:---:|---|----------|
| `source_file_path` | String | ✅ Да | — | Полный путь к исходному файлу. |
| `destination_folder_path` | String | ❌ Нет | `''` (пустая строка) | Путь к целевой папке. Если не указан, файл скопируется в корневую рабочую директорию сценария робота. |

### Выходные параметры (Out)

| Имя | Тип | Описание |
|-----|-----|----------|
| `result` | HashTable | Объект с результатами операции. Содержит ключи: |

**Структура HashTable `result`:**
- `is_success` (Boolean): `$True` при успехе, `$False` при ошибке.
- `status_message` (String): `"OK"` или подробное описание ошибки.
- `new_file_path` (String): Итоговый абсолютный путь к скопированному файлу (пустая строка при ошибке).

##  Примеры использования

### Сценарий 1: Копирование в новую вложенную структуру
**Вход:**
- `source_file_path`: `C:\Data\report.xlsx`
- `destination_folder_path`: `D:\Archive\2026\09\Reports\`

**Результат:**
Утилита создаст папки `2026\09\Reports\` (если их нет), скопирует файл и вернет `is_success = $True`.

### Сценарий 2: Копирование в рабочую директорию робота
**Вход:**
- `source_file_path`: `.\temp\config.json`
- `destination_folder_path`: *(оставляем пустым)*

**Результат:**
Файл `config.json` будет скопирован в корневую папку, откуда запущен робот.

##  Логирование
Утилита использует стандартизированный формат логов для удобства фильтрации:
- Начало: `[INFO]:[copy-file]: Запуск обработки...`
- Конец: `[INFO]:[copy-file]: Обработка завершена`

## ❗ Обработка ошибок
В случае любой ошибки утилита **не прерывает** работу родительского сценария. В поле `status_message` будет возвращен понятный текст:
- `"Путь к источнику не может быть пустым"`
- `"Исходный файл не найден: ..."`
- `"Превышен лимит длины пути: ..."`
- `"Ошибка создания директории: ..."`
- `"Ошибка выполнения задачи - ..."` (для любых непредвиденных ситуаций)
